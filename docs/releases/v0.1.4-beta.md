# Forma v0.1.4-beta

## Chat composer

- The message field expands as you type, up to a comfortable reading height.
- Once the field reaches its limit, it scrolls internally without hiding the active text or changing the workspace layout.
- The existing local learning session, note mentions, attachments, and quiz handoffs remain unchanged.

## Implementation decision

Forma does not add `assistant-ui` in this release. Its initializer scaffolds an AI-SDK runtime and replacement thread components, while Forma currently uses a custom persisted learning workflow. The existing composer was repaired directly to keep that working product behavior intact.
