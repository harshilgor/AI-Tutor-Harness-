# Forma v0.1.1-beta

This beta fixes desktop web asset serving. The previous installer could render the local interface without its CSS, producing an unstyled page. Forma now serves bundled stylesheets and JavaScript directly from its loopback server.

## Included

- In-app Windows update checks from **Workspace Settings** and the **File** menu.
- Downloaded updates install only after selecting **Restart and install**.
- The existing local learning data and encrypted provider credentials remain outside the application installation and are preserved during updates.

## Verify the download

Download the matching installer and `SHA256SUMS` from this release. Compute the installer SHA-256 hash and compare it with the matching checksum before installation.

## Known limitations

- The in-app updater is currently available for signed Windows Squirrel releases. macOS update delivery remains manual while the macOS updater channel is implemented and validated.
- This is a local beta: accounts, synchronization, hosted model access, billing, and collaboration are not included.
