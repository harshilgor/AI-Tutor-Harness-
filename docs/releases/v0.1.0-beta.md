# Forma v0.1.0-beta

Forma is a local-first desktop beta for guided learning and quizzes. Learner state, quiz history, review schedules, and imported materials remain on the device. Configure an OpenRouter or OpenAI provider key in **Your workspace** for model-backed lessons and quizzes; deterministic teaching remains available without a key.

## Included

- Ask and Learn in a shared conversation workspace.
- Guided teaching routes, inline understanding checks, and resumable learner journeys.
- Adaptive Quiz generation, evaluation, repair guidance, and conservative learner-evidence updates.
- Local SQLite storage, JSON export and deletion controls, encrypted local provider-key storage, and optional review notifications.
- Signed Windows x64 installer and signed/notarized macOS installers for Intel and Apple Silicon.

## Verify the download

Download the matching installer and `SHA256SUMS` from this release. Compute the SHA-256 hash of the installer and compare it with the corresponding line in `SHA256SUMS` before installation.

## Data compatibility

This beta upgrades the existing local database in place and preserves local learner data across application updates and uninstall/reinstall. Before testing an upgrade, export data from **Your workspace** or copy the application-data directory. The release process validates upgrades from two prior supported builds before publishing.

## Known limitations

- This is a local beta: accounts, synchronization, hosted model access, billing, and collaboration are not included.
- Automatic updates are not enabled. Install later beta builds manually from GitHub Releases.
- Calibrated mastery and retrieval-backed source verification are still under development.
- The normal interactive Windows uninstall flow requires final end-user-machine verification. Uninstall intentionally preserves learner data.
- Linux builds are not provided.

## Rollback

Quit Forma, restore a copy of the pre-upgrade application-data directory, and reinstall the previous installer. Do not open an older build against an upgraded database unless the pre-upgrade data directory has been restored.
