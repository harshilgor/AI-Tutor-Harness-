# Forma v0.1.3-beta

## Workspace experience

- Keeps the application frame fixed, with independent scrolling for chat and notes.
- Keeps the chat composer visible while a conversation grows.
- Adds a dedicated **Notes** destination in the primary sidebar, backed by the existing local notes, links, and backlinks.
- Removes the nested “A closer look” panel. Selected lesson text can be sent back into the normal chat or saved as a note.
- Hides the obsolete interactive-preview control from the workspace header.

## Update

Install the signed Windows setup file for this version over any prior Forma beta. Existing local tutor data and notes remain in place.
