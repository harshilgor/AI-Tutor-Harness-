# Forma v0.1.2-beta

This beta fixes local model-provider activation. Previously, an OpenAI or OpenRouter key could be saved in the desktop credential store without selecting the associated backend provider. Forma now selects the most recently configured provider and passes that selection to the local tutor service when it starts.

## Included

- Saving an OpenAI key activates the OpenAI provider after restarting Forma.
- Saving an OpenRouter key activates the OpenRouter provider after restarting Forma.
- Removing the active provider key returns Forma to the built-in deterministic experience unless another supported key is configured.

## Verify the download

Download the matching installer and `SHA256SUMS` from this release. Compute the installer SHA-256 hash and compare it with the matching checksum before installation.

## Known limitations

- A model setting screen with explicit provider/model choice is planned. This beta uses the most recently configured supported provider.
- The in-app updater is currently available for signed Windows Squirrel releases. macOS update delivery remains manual while the macOS updater channel is implemented and validated.
