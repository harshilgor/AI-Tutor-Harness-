# Forma v0.1.5-beta

## Chat history

- The sidebar now keeps a persistent Recent chats list with Today / Yesterday / Previous 7 days / Older grouping, search, rename, and delete.
- Reopening a conversation restores its full message history; each learner's history stays isolated.
- Conversation titles derive from the first message; no extra model call.

## Living study notes

- Every Learn chat can own a living study note, created at session start and linked both ways between chat and Notes.
- The tutor distills lessons, side explorations, and quiz gaps into concise section proposals — never transcript dumps. Review them inline in chat or inside the Notes editor with Accept · Edit · Reject.
- Section ownership (tutor/user/shared), tombstones, and revision protection live outside the Markdown, so the note stays a clean document.
- Per-note tutor-update modes: ask first (default), auto-add, or never.

## Settings

- Settings is now a fullscreen page with General, API keys, Notifications, Data & privacy, and About categories.
- API keys can be added from the browser: keys are stored in the local tutor service configuration and take effect after a service restart. The desktop app keeps using the OS credential store.
- The Learner menu border now matches the chat input weight.

## Usage analytics

- Local token, generation, and cost summaries with trend, top sessions, and time-range views, computed on-device from generation records.

## Implementation decision

Forma does not auto-persist Ask or side-chat content; those save only through explicit action. Quiz attempts and learner evidence keep their independent lifecycle and are preserved when a chat is deleted.
